## 工具汇总与分类优化计划

### 一、问题分析

1. **功能重叠**：container\_check 与 docker 工具功能重叠，且 docker 工具功能更全面
2. **分类不明确**：部分工具分类不够清晰，如磁盘/IO 检查功能分散在多个工具中
3. **描述不一致**：部分工具描述使用英文，需要统一改为中文

### 二、优化方案

#### 1. 工具分类合并

* **系统基础工具**：

  * system\_status：系统基础信息查询

  * process\_check：进程与 CPU/内存 排查

  * service\_check：系统服务与日志检查

* **Docker工具**：

  * 保留 docker 工具，其功能已涵盖 container\_check 中的 Docker 相关功能

  * 将 container\_check 中剩余的磁盘/IO 检查功能（df, du, iostat, lsof）移至新的系统工具

* **数据库工具**：

  * mysql\_query：MySQL 数据库查询工具

* **监控工具**：

  * prometheus：Prometheus 指标查询

* **CI/CD工具**：

  * jenkins\_tools：Jenkins 工具

* **文件工具**：

  * files\_query：文件查询工具

  * read\_file：文件读取工具

* **管理工具**：

  * control\_center：控制工具启用/禁用

#### 2. 具体修改内容

##### 2.1 修改 system\_check\_tools.py

* 移除 ContainerCheckTool 类

* 将原 container\_check 工具中的磁盘/IO 检查功能（df, du, iostat, lsof）移至 system\_check\_tools.py 中的适当位置

* 更新所有工具描述为纯中文

##### 2.2 修改 docker\_tools.py

* 更新描述为纯中文

* 确保包含所有 Docker 相关功能

##### 2.3 修改其他工具文件

* 更新所有工具描述为纯中文

* 确保工具名称和描述清晰反映其功能

##### 2.4 移除重复功能

* 移除 container\_check 工具，因为其 Docker 相关功能已被 docker 工具涵盖

* 保留并优化磁盘/IO 检查功能

### 三、预期效果

1. 工具分类更明确，用户可以更容易找到所需工具
2. 功能重叠减少，避免用户困惑
3. 描述统一为中文，提升用户体验
4. 工具名称和描述更准确反映其功能

### 四、实施步骤

1. 备份现有工具文件
2. 修改 system\_check\_tools.py，移除 ContainerCheckTool 类
3. 将磁盘/IO 检查功能移至 system\_check\_tools.py
4. 更新所有工具描述为纯中文
5. 修改 docker\_tools.py 描述为中文
6. 修改其他工具描述为中文
7. 测试工具功能正常
8. 更新相关文档
