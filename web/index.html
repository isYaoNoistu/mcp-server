平台使用说明

1. MCP工具概述

MCP (Model Control Platform) 是一个用于管理和控制各种工具的平台，支持通过JSON-RPC协议调用各种工具。

2. 工具调用方式

使用CherryStudio配置文件调用MCP工具，配置文件路径： cherry\cherry_mcp.json

{"mcpServers": {
  "mcp-server": {
    "type": "http",
    "url": "http://127.0.0.1:8000/mcp"
  }
}
}

将此配置文件导入CherryStudio，即可通过CherryStudio管理和调用MCP工具。

3. 工具列表

在工具管理页面可以查看所有可用工具及其状态，通过开关可以启用或禁用特定工具。

4. 配置说明

在配置工具页面可以配置各工具的参数，配置将自动保存到.env文件中。
